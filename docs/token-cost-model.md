- 免费版正常使用成本上限（重度 110 次/月）约 **¥2–4/月**，典型用户 <¥1/月，远低于此前笼统假设的 ¥6.72/用户/月；极端滥用（3,000 次/月）理论 ¥72/月，属风控边界，不应作为计价依据。
