# AI 投资决策 Agent V0.2

面向内部体验验证的 A 股投资假设研究原型。产品不替用户直接下结论，而是将观点放入动态候选、正反审查、风险控制和短期执行规则中检验。

## V0.2 体验重点

- 市场观点与指定个股双入口
- 面向沪深京 A 股的全市场检索交互设计
- 根据问题动态选择 2～3 个验证标的，不固定候选类型
- 乐观、悲观、风控和裁决官四视角分析
- 可选“我的交易系统”：保存后在风控委员与裁决官之间独立推导
- 用户规则严格按原文执行；缺失条件显示“依据不足”，不自动补写
- 逻辑、证据、兑现、拥挤和风控五维评分
- 一周执行卡只展示仓位比例：首次 5%，确认后最高 10%
- 明确价格参考：限价 ¥162、止损 ¥157、止盈 ¥175～178
- 每次分析按任务标题留档，并保存研究、行动方案和当次交易系统快照
- 组合体检：支持从档案或手动录入股票，生成组合评分、风险重叠、交易系统冲突和绿色高分组合推荐
- 复盘教练：支持个股/组合复盘，区分无法提前规避和可以优化的决策行为
- AI 生成提示、二次风险确认和到期失效机制

## 当前数据边界

- 行情：进入页面与点击「最新行情 · 重置」时，从东方财富 / 腾讯免费实时接口抓取 A 股真实行情（盘中实时、盘后为最新收盘价）；
- 分析：由 DeepSeek `deepseek-v4-flash` 真实生成，候选价格使用行情快照真实数值，不虚构标的与价格；
- 组合体检与复盘：基于用户录入的标的、留档的观察计划与实际操作记录生成；
- 不自动读取券商成交数据；不构成持牌证券投资建议。

## 本地持久化

原型不依赖服务端数据库，数据只保存在当前浏览器：

- `thesis-ai-trading-system`：当前启用的自然语言交易规则及更新时间；
- `thesis-ai-archives`：分析档案、行动参数和当次交易规则快照；
- `thesis-ai-portfolio`：组合体检名单、来源和模拟仓位；
- `thesis-ai-reviews`：复盘教练生成的个股/组合复盘历史。

清除浏览器站点数据会同时删除上述内容。旧版本档案缺少新字段时，页面会使用任务主题及默认行动参数兼容展示。

## 运行与部署

```bash
npm run demo:build     # 构建后启动本地服务（真实行情 + 真实 AI）→ http://127.0.0.1:8787
```

- 行情：每次进入页面自动从免费实时行情接口抓取（东方财富 push2，腾讯兜底）；点「最新行情 · 重置」重新抓取。
- AI：分析助手与股票识别由 DeepSeek `deepseek-v4-flash` 真实生成；组合体检/复盘基于本地规则生成；API key 经服务端代理调用，不进入前端。
- key 解析顺序：环境变量 `DEEPSEEK_API_KEY` > 项目 `.env.local`（已 gitignore，不会被提交）> OpenClaw 本地 auth 存储（`~/.openclaw/.../openclaw-agent.sqlite`，自动读取）。
- 付费分层：免费版基础分析不限次，组合体检+复盘共 10 次；专业版 29 元/月全功能不限次。
